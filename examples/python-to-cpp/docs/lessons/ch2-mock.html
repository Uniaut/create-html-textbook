45분 모의 코딩 테스트

자료구조 선택 5분, 구현 25분, 검증 15분을 기준으로 진행하세요. C++17에서 자료형과 중복 처리를 스스로 결정하는 연습입니다.

문제 · 인접한 고유 좌표

첫 줄에 N (2~200,000), 다음 줄에 절댓값이 최대 10억인 정수 좌표 N개가 주어집니다. 원래 입력 순서대로 각 좌표의 0부터 시작하는 압축 순위를 한 줄로 출력하세요. 둘째 줄에는 서로 다른 좌표를 정렬했을 때 가장 큰 인접 간격을 출력하세요. 고유 좌표가 하나라면 간격은 0입니다.

입력
5
9 -4 9 2 -4

출력
2 0 2 1 0
7

검증 체크

  • 모두 같은 좌표일 때 순위와 간격이 모두 0이다.
  • 중복이 있는 내림차순 입력에서도 원래 입력 순서대로 순위를 출력한다.
  • 정렬과 순위 조회의 전체 시간 복잡도를 설명한다.

마지막으로 격자 BFS를 파일 도움 없이 다시 구현해 두 유형의 실수를 기록하세요.
