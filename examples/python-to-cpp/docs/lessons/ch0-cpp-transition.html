Python 풀이를 C++로 옮기기

알고리즘을 선택한 다음 컨테이너와 정수 범위를 먼저 적어 보세요. Python에서 암묵적으로 처리하던 두 가지가 C++ 구현의 출발점입니다.

자료구조 대응

PythonC++17차이
liststd::vector<T>요소 타입을 고정한다.
deque (FIFO)std::queue<T>front()로 읽고 pop()으로 제거한다.
dictstd::unordered_map<K,V>operator[]는 없는 키를 삽입한다. 존재 여부는 find()로 검사한다.

손으로 검증하기

정수 200,000개가 각각 최대 10억일 때 합의 최댓값을 계산하고 누적 변수의 타입을 정하세요. 곱셈을 할 때는 결과를 저장하기 전에 피연산자의 타입이 결정된다는 점도 확인하세요.

완료 체크

  • 빈 큐에서 front()를 호출하지 않는다.
  • 200000LL * 1000000000이 필요한 이유를 설명한다.
