격자 BFS를 C++로 구현하기

Python의 deque로 작성하던 최단 경로를 C++17로 옮깁니다. 큐에 넣는 시점에 거리를 기록해 각 칸이 한 번만 들어가도록 설계합니다.

문제

첫 줄에 행과 열(각 1~1,000), 다음 줄부터 격자가 주어집니다. .은 통로이고 #은 벽입니다. 양 끝점은 통로입니다. 왼쪽 위에서 오른쪽 아래까지 상하좌우로 이동할 때 최단 이동 횟수를 출력하세요. 도달할 수 없다면 -1을 출력하세요.

큐와 거리 배열

std::queue<std::pair<int, int>>는 처리할 칸을 담고, 거리 배열의 -1은 미방문을 뜻합니다. 거리 0과 미방문을 분리하면 1×1 격자도 같은 규칙으로 처리할 수 있습니다.

함수의 const std::vector<std::string>&가 낯설다면 1.1 참조와 복사를 먼저 읽으세요.

실습 및 검증

grid.cpp의 shortest_path를 구현하세요. 예제 폴더의 lab/에서 아래 명령을 실행합니다. 시작 상태에서는 막힌 격자만 통과합니다.

c++ -std=c++17 -Wall -Wextra -pedantic grid.cpp -o grid
python3 check.py ./grid

네 테스트를 통과하고 시간과 추가 공간이 모두 O(행 × 열)인 이유를 설명하면 완료입니다.
