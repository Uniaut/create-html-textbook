격자를 복사 없이 전달하기

격자 BFS의 입력은 함수 안에서 읽기만 합니다. const T&로 받으면 호출자가 가진 객체를 그대로 읽고, 함수에서는 그 참조를 통해 수정할 수 없습니다.

시그니처 비교

매개변수기존 변수로 호출했을 때
T grid별도 복사본을 받는다.
T& grid원본에 접근하고 수정할 수 있다.
const T& grid복사 없이 원본을 읽는다.
